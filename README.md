# מגיע לי

אפליקציית החזרי מס לשכירים. המשתמש עונה על שאלון, מזין את הנתונים מטופסי 106 ומאישורי ביטוח לאומי, ומקבל לכל שנה כמה מגיע לו ורשימת שדות מוכנה לדו"ח 1301 באתר רשות המסים. ההגשה נעשית על ידי המשתמש.

הכול רץ בדפדפן. אין הרשמה, ומסמכים לא נשלחים לשום מקום. החריג היחיד הוא מונה אנונימי (ראו `worker/`).

## מבנה
| תיקייה | מה יש בה |
|---|---|
| `site/` | האתר עצמו, סטטי, בלי שלב בנייה. `index.html` דף פתיחה (טלפון), `app.html` האשף (מחשב), `admin.html` מסך ניהול |
| `site/js/params.js` | **טבלת הפרמטרים לכל שנה**, עם סטטוס אימות לכל ערך. ערך לא מאומת עוצר את החישוב |
| `site/js/engine.js` | מנוע החישוב (קוד טהור) |
| `site/js/guide.js` | מדריך המילוי לפי לשוניות 1301 |
| `site/js/app.js` | האשף והשאלון |
| `tests/` | מקרי בדיקה. מקרה ראשון: 2020, תיק אמיתי, תואם לכפתור "חישוב" של רשות המסים (7,941 ₪) |
| `worker/` | שרת אנליטיקס אנונימי (Cloudflare Worker) |
| `docs/` | האפיון, יומן השאלות והידע, נוסח מסך הפתיחה ומחקר מודל עסקי |

## הרצה מקומית
```
npm test           # כל מקרי הבדיקה
npm start          # האתר ב-http://localhost:3000
```

## פרסום (GitHub Pages)
כל מיזוג ל-`main` מריץ את הבדיקות ומפרסם את `site/` ל-GitHub Pages. בחשבון חינמי זה עובד רק כשהריפו ציבורי.

הקמה, פעם אחת: Settings → General → Change visibility → Public, ואז Settings → Pages → Source: GitHub Actions. הכתובת: `https://doront2311-del.github.io/I-deserve-it/`.

חלופה אם הריפו צריך להישאר פרטי: Cloudflare Pages (חינם). מחברים את הריפו, Build command ריק, Build output directory `site`.

**מה לא נכנס לריפו:** מסמכים, צילומי מסך מהאזור האישי, ופרטים מזהים של מקרי בדיקה. אלה נשמרים בתיקיית הפרויקט הפרטית. מקרי הבדיקה בקוד מופיעים בלי שמות.

## עקרונות (מהאפיון)
1. אפס הנחות: כל שאלה חובה, בלי ברירות מחדל.
2. מקור לכל שדה בפלט.
3. פרטיות: הכול בדפדפן.
4. שקיפות: התוצאה באותן שורות כמו מסך "חישוב" של רשות המסים.
5. עצירה במקרה ספק, והפניה לרואה חשבון.
6. לא ייעוץ.
7. דיוק מדורג: שנה קודם, תאריך מדויק רק כשהוא משנה.
